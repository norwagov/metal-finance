Jak podłączyć subskrypcję

  1. Na dowolnym komputerze z zainstalowanym Claude Code uruchom claude setup-token i zaloguj się kontem z planem Pro lub Max.
  2. Skopiuj wypisany token (ważny rok) do CLAUDE_CODE_OAUTH_TOKEN w pliku docker-compose.yml.
  3. Zrestartuj kontener: docker compose up -d.

Aplikacja celowo ignoruje ANTHROPIC_API_KEY, żeby nic nie poszło na rachunek płatnego API. Token daje dostęp do Twojej subskrypcji - trzymaj aplikację tylko dla swojej ekipy (ustaw APP_PASSWORD).
